# Blend

Размещение базового актива из приватного пула в поставку Blend и возврат этого актива в приватный пул.

## Language

**Interest Deposit**:
Неотчуждаемый остаток долей одного G-адреса на одном резерве одного пула. У одного человека на одной паре пул–резерв таких записей может быть много.
_Avoid_: вклад, позиция, одноразовый адрес

**Позиция**:
Запись адаптера в пуле Blend. На одном пуле у адаптера одна позиция, и в ней лежит общая поставка всех interest deposit этого пула.
_Avoid_: interest deposit

**Адаптер**:
Контракт, который держит позицию и может вернуть базовый актив только в приватный пул.
_Avoid_: vault, router

**Ставка**:
Заданный для токена годовой процент, который интерфейс показывает для этого токена.
_Avoid_: b_rate, курс, APR пула

**Индекс цепочки**:
Номер адреса interest deposit среди адресов, выведенных из одного spend scalar, одного пула и одного токена. Любой номер выводится отдельно, без предыдущих ключей.
_Avoid_: nonce interest deposit, nonce транзакции, nonce ZK-конфига

**Пакетный вывод**:
Возврат нескольких interest deposit одного пула и одного резерва одной транзакцией. Адреса подписывают её вместе, и наблюдатель видит эту связь. Адреса могут принадлежать разным людям.
_Avoid_: пакетный депозит
