# Подпись G не включает пруф

G подписывает аргументы адаптера без байтов пруфа. Публичные сигналы входят в эту подпись с обнулённым `stateRoot`, как в хеше KYT, шифртекст входит тоже. `from` у `transact` — адаптер: пул требует подпись на фактический пруф, и её даёт сам контракт. Новый пруф на другой корень из истории корней проходит со старой подписью G, если остальные сигналы совпали.

## Considered Options

- Включить пруф в подпись G. Отклонено: смена корня пула требует новой подписи.
- Менять `transact`, чтобы пул не подписывал пруф. Отклонено: контракт пула не меняется.
