# Депозиты не связаны, пакетный вывод связывает подписантов

Каждый interest deposit проходит отдельной транзакцией: её подписывает только его G, основной кошелёк в ней не участвует, а счёт G и комиссию оплачивает общий relay. Пакетный вывод устроен так же: платит relay, основного кошелька в транзакции нет, и новая связь возникает только между G, которые подписали пакет. Пакет один на пул и резерв. Каждый G подписывает общий вызов, поэтому наблюдатель видит, что эти адреса действовали вместе. Контракт не проверяет общий spend scalar: проверка связала бы G с приватным адресом и не дала бы в будущем собрать пакет из депозитов разных людей.

## Considered Options

- Запретить пакетный вывод. Отклонено: несколько interest deposit нужно забирать одной транзакцией.
- Требовать один spend scalar на пакет. Отклонено: проверка раскрывает связь с приватным адресом.
