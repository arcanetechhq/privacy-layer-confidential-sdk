# Адрес interest deposit выводится цепочкой HKDF

Адрес interest deposit — это Ed25519-ключ из `HKDF-SHA256`. IKM — 32 байта spend scalar, salt — UTF-8 `arcane-blend-position-v1`, info — 32 байта идентификатора пула Blend, затем 32 байта идентификатора токена, затем индекс цепочки как `u32` big-endian. На выходе 32 байта seed. Контракт индекс не хранит: следующий депозит занимает наименьший индекс без записи, а полный вывод оставляет запись с нулём, чтобы индекс не использовать снова.

## Considered Options

- `SHA-256` от скаляра и nonce, который хранит контракт. Отклонено: цепочка из скаляра, пула и токена восстанавливается без отдельного nonce.
- Кодировать в info strkey адресов. Отклонено: текст адреса зависит от кодировки, сырой идентификатор контракта нет.
